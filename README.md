# 🕹️ Falling Blocks: Classic Brick Edition

A modern, high-octane falling blocks puzzle game inspired by vintage 99-in-1 handheld brick consoles, reimagined with silky smooth grid animations, vivid retro-arcade palettes, tactile audio synthesis, and authentic scoring mathematics.

## ✨ Features
- **Silky Smooth Piece Descent:** Hardware-accelerated CSS translation transitions paired with strict deterministic grid logic.
- **Classic Handheld Brick Aesthetic:** Vintage LCD grid styling, amber/cyberpunk neon palettes, and retro digital 7-segment displays.
- **3 Difficulty Tiers:**
  - *Easy (Novice Brick):* High I-bar/O-block spawn rates, gentle drop speed.
  - *Medium (Arcade Standard):* Balanced 7-bag randomizer, progressive level speeds.
  - *Hard (Master Brick):* Elevated S/Z obstacle frequency, fast-paced gravity, maximum score multiplier.
- **Web Audio Sound Effects:** Real-time retro synth tones for moves, rotations, hard drops, and multi-line tetrises.
- **Dual Control Schemes:** Full keyboard arrow/WASD mapping + responsive on-screen tactile game buttons for mobile/touch devices.
- **PWA Ready:** Installable as an offline app with developer identity declared as **Ayush Kumar**.

## 📲 How to Install as an App & Generate Android APK

### 1. Direct Install on Phone (PWA - 1 Tap)
- Open the live game link in Chrome (Android) or Safari (iOS).
- Click the **"INSTALL APP / APK GUIDE"** button on the title screen, or:
  - **Android / Chrome:** Tap the 3 dots (`⋮`) at top right -> Select **"Install app"** or **"Add to Home screen"**.
  - **iOS / Safari:** Tap the **Share icon** at bottom -> Select **"Add to Home Screen"**.
- The game will appear as an app with custom icon and Ayush Kumar branding in your app drawer.

### 2. Generate a Standalone Android APK (`.apk`)
To share an installable `.apk` file directly over WhatsApp or upload to the Google Play Store:
1. Open [PWABuilder](https://www.pwabuilder.com) in your browser.
2. Enter the live hosted URL of this game.
3. Click **"Package for Android"**.
4. Download the ready-to-install Android APK file!

## 🚀 Quick Start (Running from ZIP / GitHub)

### 1. Extract ZIP & Install Dependencies
```bash
npm install
```

### 2. Run Locally in Development
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 3. Build for Production
```bash
npm run build
```
